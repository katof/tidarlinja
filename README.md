# Tíðarlinja

Ein einføld, vatnrøtt tíðarlinja yvir útgávur ávegis, í litunum og stavsniðinum hjá nam.fo.

**Síðan:** https://katof.github.io/tidarlinja/

## Soleiðis rættar tú útgávurnar

1. Opna fíluna `utgavur.js` her á GitHub.
2. Trýst á blýantin (Edit this file).
3. Rætta, legg aftrat ella strika útgávur. Hvør útgáva hevur `tid` (t.d. "heyst 2027"), `heiti`, `slag`, `fak`, `stoda` og `tekstur`.
4. Trýst á **Commit changes**. Síðan dagførist eftir eini løtu.

`stoda` kann vera: Ætlað, Í skriving, Í umbróti, Til prentingar ella Útkomin.
